Because typing updates state, and React re-renders a component whenever its state changes. That's normal, not a bug.

```jsx
const [text, setText] = useState("");
<input value={text} onChange={e => setText(e.target.value)} />
```

Each keystroke calls `setText`, so the component re-runs and the UI shows the new value.

It only matters if the re-render is slow. Then move the input's state into its own small component, or wrap the heavy child in `React.memo`.
