It depends on whether you want to keep the changes from that commit.

**Keep the changes, undo only the commit** (changes stay staged):

```
git reset --soft HEAD~1
```

**Keep the changes, but unstaged:**

```
git reset HEAD~1
```

(`--mixed` is the default, so this is the same as `git reset --mixed HEAD~1`.)

**Throw away the commit and its changes entirely** (destructive):

```
git reset --hard HEAD~1
```

**If you've already pushed the commit**, don't rewrite history on a shared branch. Create a new commit that reverses it instead:

```
git revert HEAD
```

If you only want to fix the commit message or add a forgotten file, you don't need to undo it. Use `git commit --amend`.

If you reset by mistake, `git reflog` shows where HEAD used to be. You can then recover with `git reset --hard <hash>`.
