Generally no, not for anything sensitive. Any JavaScript running on your page can read localStorage, so a single XSS bug or compromised third-party script lets an attacker steal the token and use it from anywhere. Store the JWT in an HttpOnly, Secure, SameSite cookie instead, since scripts can't read it. localStorage is only defensible for short-lived, low-privilege tokens in an app where you're confident no untrusted script can run.
