Run:

```
git reset --soft HEAD~1
```

This removes the commit but keeps your changes staged, so you can edit and recommit.

If you want the changes unstaged instead, use `git reset HEAD~1`. If you want them gone entirely, use `git reset --hard HEAD~1`, which permanently discards them.

If you've already pushed the commit, don't reset. Use `git revert HEAD`, which adds a new commit that undoes it without rewriting shared history.
