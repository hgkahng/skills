That's normal: typing in the input changes state, and React re-renders a component whenever its state changes.

```jsx
const [text, setText] = useState("");
<input value={text} onChange={e => setText(e.target.value)} />
```

Each keystroke calls `setText`, so React re-runs your component function to show the new value. That's how controlled inputs work, and it's fast enough that you usually don't need to fix it.

It only matters if the re-render is slow. In that case, move the input and its state into its own small component so the rest of the page doesn't re-render.
