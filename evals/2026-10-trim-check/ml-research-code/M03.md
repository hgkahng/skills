**Plan**
- One script, `finetune.py`: ImageNet-pretrained ResNet-18 with a new 10-way head, with all layers fine-tuned.
- Random seeded train/val split of one `ImageFolder` root. Train gets augmentation and val gets a deterministic resize and crop, so they use two dataset objects over the same files, indexed by `Subset`.
- AMP via `autocast` and `GradScaler`. Every epoch writes `ckpt.pt` (model, optimizer, scheduler, scaler, epoch, best accuracy), and `--resume` continues from it.

```python
import argparse
import random
from pathlib import Path

import numpy as np
import torch
import torch.nn as nn
from torch.utils.data import DataLoader, Subset
from torchvision import datasets, models, transforms as T

p = argparse.ArgumentParser()
p.add_argument("--data", required=True, help="ImageFolder root: data/<class>/*.jpg")
p.add_argument("--ckpt", default="ckpt.pt")
p.add_argument("--epochs", type=int, default=15)
p.add_argument("--bs", type=int, default=64)
p.add_argument("--lr", type=float, default=0.01)
p.add_argument("--val-frac", type=float, default=0.2)
p.add_argument("--workers", type=int, default=4)
p.add_argument("--seed", type=int, default=0)
p.add_argument("--resume", action="store_true")
args = p.parse_args()

random.seed(args.seed)
np.random.seed(args.seed)
torch.manual_seed(args.seed)  # also seeds all CUDA devices

dev = torch.device("cuda" if torch.cuda.is_available() else "cpu")
amp = dev.type == "cuda"

# --- data: split indices once (same split on every run/resume), then pick transforms per split
norm = T.Normalize([0.485, 0.456, 0.406], [0.229, 0.224, 0.225])
train_tf = T.Compose([T.RandomResizedCrop(224), T.RandomHorizontalFlip(), T.ToTensor(), norm])
val_tf = T.Compose([T.Resize(256), T.CenterCrop(224), T.ToTensor(), norm])
train_full = datasets.ImageFolder(args.data, train_tf)
val_full = datasets.ImageFolder(args.data, val_tf)
perm = torch.randperm(len(train_full), generator=torch.Generator().manual_seed(args.seed)).tolist()
n_val = int(len(perm) * args.val_frac)
train_ds, val_ds = Subset(train_full, perm[n_val:]), Subset(val_full, perm[:n_val])

g = torch.Generator()  # drives shuffling and, via the loader's base seed, worker augmentation
train_dl = DataLoader(train_ds, args.bs, shuffle=True, num_workers=args.workers,
                      pin_memory=amp, generator=g, drop_last=True)
val_dl = DataLoader(val_ds, args.bs, num_workers=args.workers, pin_memory=amp)

# --- model / optimization
model = models.resnet18(weights=models.ResNet18_Weights.DEFAULT)
model.fc = nn.Linear(model.fc.in_features, len(train_full.classes))
model.to(dev)
opt = torch.optim.SGD(model.parameters(), lr=args.lr, momentum=0.9, weight_decay=1e-4)
sched = torch.optim.lr_scheduler.CosineAnnealingLR(opt, T_max=args.epochs)
scaler = torch.amp.GradScaler(dev.type, enabled=amp)
crit = nn.CrossEntropyLoss()

start, best = 0, 0.0
if args.resume:
    ck = torch.load(args.ckpt, map_location=dev)
    model.load_state_dict(ck["model"])
    opt.load_state_dict(ck["opt"])
    sched.load_state_dict(ck["sched"])
    scaler.load_state_dict(ck["scaler"])
    start, best = ck["epoch"] + 1, ck["best"]
    print(f"resumed from epoch {ck['epoch']} (best val acc {best:.4f})")

for epoch in range(start, args.epochs):
    g.manual_seed(args.seed + epoch)  # per-epoch seed, so a resumed run sees the same batches
    model.train()
    total = 0.0
    for x, y in train_dl:
        x, y = x.to(dev, non_blocking=True), y.to(dev, non_blocking=True)
        opt.zero_grad(set_to_none=True)
        with torch.autocast(dev.type, enabled=amp):
            loss = crit(model(x), y)
        scaler.scale(loss).backward()
        scaler.step(opt)
        scaler.update()
        total += loss.detach() * len(x)
    sched.step()

    model.eval()
    correct = 0
    with torch.inference_mode(), torch.autocast(dev.type, enabled=amp):
        for x, y in val_dl:
            x, y = x.to(dev, non_blocking=True), y.to(dev, non_blocking=True)
            correct += (model(x).argmax(1) == y).sum()
    acc = correct.item() / len(val_ds)
    best = max(best, acc)
    print(f"epoch {epoch}  train loss {total.item() / (len(train_dl) * args.bs):.4f}  val acc {acc:.4f}")

    ck = dict(model=model.state_dict(), opt=opt.state_dict(), sched=sched.state_dict(),
              scaler=scaler.state_dict(), epoch=epoch, best=best)
    torch.save(ck, tmp := args.ckpt + ".tmp")
    Path(tmp).replace(args.ckpt)  # atomic: a crash mid-save can't corrupt the last good checkpoint
    if acc == best:
        torch.save(model.state_dict(), "best.pt")
```

Usage: `python finetune.py --data path/to/images`, and add `--resume` to continue after an interruption.

**Notes**
- **Not run.** I had no environment, so this is untested. A one-epoch run on a small subset is the first thing to try.
- **Validation is used for model selection.** `best.pt` is chosen by val accuracy, so that number is slightly optimistic. If you need an unbiased final figure, hold out a separate test split and evaluate it once at the end.
- **Split:** it is random, not stratified. With very small or imbalanced classes, stratify instead. The split depends only on `--seed`, so it is identical on resume. Changing `--seed` or `--val-frac` between runs changes the split, so don't do that when resuming.
- **Reproducibility:** this is reproducible, not bit-deterministic. I did not set `cudnn.deterministic`, because it costs speed. Without it, repeat runs can differ slightly on GPU. The per-epoch `g.manual_seed(...)` is what lets a resumed run see the same batches and augmentations as an uninterrupted one. I believe the loader's base seed is drawn from `g`, but I haven't verified that on your torch version.
- **Settings you may want to change:** `--lr 0.01` with SGD and cosine decay is a common default for full fine-tuning, so tune it. `--epochs 15` is arbitrary. If you change `--epochs` on resume, the cosine schedule's `T_max` is restored from the checkpoint, not recomputed.
- **Mixed precision:** AMP is only enabled on CUDA. On CPU the script runs in fp32, and the scaler is a no-op.
- **Pretrained weights:** `ResNet18_Weights.DEFAULT` is downloaded on first use, so the first run needs internet access. After that it is cached.
- **Training loss:** `drop_last=True` keeps batch sizes uniform, so the epoch loss is divided by `len(train_dl) * args.bs`.
