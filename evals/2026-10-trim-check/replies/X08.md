Here is the transformer encoder block as a standalone `.tex`. You didn't name a layout, so I took a single-column NeurIPS figure: thin 0.5pt lines, `\footnotesize` labels, Times fonts to match the body text, and light fills that survive grayscale printing.

Forward-pass order, bottom to top: input embedding, multi-head attention, Add & Norm, feed-forward, Add & Norm. The two residual connections run on the right of the main flow. Each one branches off the input of its sublayer and enters the Add & Norm that closes that sublayer. The dashed frame marks the part that is repeated $N$ times.

```latex
\documentclass[border=4pt]{standalone}
\usepackage{mathptmx} % Times, to match the NeurIPS body text
\usepackage{tikz}
\usetikzlibrary{positioning,calc,fit,arrows.meta}

% ---- Styles: define each box / arrow type once ----
\tikzset{
  node distance=0.9cm,
  block/.style={
    draw=black, line width=0.5pt, rounded corners=2pt,
    minimum width=3.8cm, minimum height=0.8cm,
    align=center, font=\footnotesize
  },
  emb/.style ={block, fill=white},     % input
  sub/.style ={block, fill=blue!10},   % sublayers (structure)
  norm/.style={block, fill=black!8},   % Add & Norm
  arr/.style ={-{Stealth[length=4pt,width=3pt]}, line width=0.5pt},
  dot/.style ={circle, fill=black, inner sep=0.9pt},
  rep/.style ={draw=black!55, dashed, line width=0.4pt,
               rounded corners=3pt, inner sep=6pt},
  note/.style={font=\scriptsize, text=black!60}   % subordinate labels
}

\begin{document}
\begin{tikzpicture}
  % Forward pass (bottom to top):
  %   Input Embedding -> Multi-Head Attention -> Add & Norm
  %   -> Feed-Forward -> Add & Norm -> output
  % Residual 1: input of Multi-Head Attention -> first Add & Norm
  % Residual 2: input of Feed-Forward         -> second Add & Norm

  \node[emb]  (emb) {Input Embedding};
  \node[sub,  above=of emb] (mha) {Multi-Head Attention};
  \node[norm, above=of mha] (an1) {Add \& Norm};
  \node[sub,  above=of an1] (ffn) {Feed-Forward};
  \node[norm, above=of ffn] (an2) {Add \& Norm};

  % subordinate labels, anchored directly under / over the main column
  \node[note, below=0.55cm of emb] (in)  {tokens $x_1,\dots,x_n$};
  \node[note, above=0.55cm of an2] (out) {encoder output};

  % residual branch points (midway between the boxes) and their right-hand rails
  \coordinate (br1) at ($(emb.north)!0.5!(mha.south)$);
  \coordinate (r1)  at ($(br1)+(2.55,0)$);
  \coordinate (br2) at ($(an1.north)!0.5!(ffn.south)$);
  \coordinate (r2)  at ($(br2)+(2.55,0)$);

  % main flow
  \draw[arr] (in)  -- (emb);
  \draw[arr] (emb) -- (mha);
  \draw[arr] (mha) -- (an1);
  \draw[arr] (an1) -- (ffn);
  \draw[arr] (ffn) -- (an2);
  \draw[arr] (an2) -- (out);

  % residual connections, routed on the right with |-
  \draw[arr] (br1) -- (r1) |- (an1.east);
  \draw[arr] (br2) -- (r2) |- (an2.east);
  \node[dot] at (br1) {};
  \node[dot] at (br2) {};

  % repeated-block frame and N x label
  \node[rep, fit=(br1)(an2)(r1)(r2)] (blk) {};
  \node[anchor=east, font=\footnotesize] at ([xshift=-3pt]blk.west) {$N\times$};
\end{tikzpicture}
\end{document}
```

Notes:
- It uses only base TeX Live packages (`standalone`, `tikz`, `mathptmx`), with the `positioning`, `calc`, `fit` and `arrows.meta` TikZ libraries.
- The residual rails sit about 0.65 cm to the right of the boxes, so they never touch the sublayers. They share one arrow style with the main flow, because both mean "data flows here".
