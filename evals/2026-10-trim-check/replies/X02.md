As designed, this comparison won't support "generalizes better." Two problems, both fatal, and both cheap to fix.

**1. You're selecting on the test set (fatal).**
Taking the best test accuracy across 20 configs is picking the maximum of 20 noisy draws, and the test set is what you're picking with. On CIFAR-10, seed-to-seed noise is often a few tenths of a percent, so the max of 20 will look better than the typical config even if the optimizer does nothing. The number you report is no longer an estimate of generalization. It is an estimate of how lucky the best config was on those 10k images.

Fix: hold out a validation split (for example 45k/5k from the training set). Pick the config by validation accuracy, then evaluate that one config on the test set once. Report that number.

**2. The baseline got 1 config and your method got 20 (fatal).**
AdamW at default settings (and especially default weight decay and no tuned schedule) is a weak baseline on CIFAR-10. Any optimizer given a 20-point search will beat it, which would tell us about the tuning budget and not about your optimizer.

Fix: give AdamW the same search budget, over the same kind of space (learning rate, weight decay, warmup/schedule, and so on), selected the same way on validation. If your 20 configs include things AdamW can't vary, say what they are, because that is part of what you're testing.

**Also worth doing, and it costs little:**
- Run 3 to 5 seeds for the selected config of each optimizer and report mean and standard deviation. If the gap is smaller than about 2 standard deviations, you don't have a result.
- "Generalizes better" is a claim about the train-test gap, but test accuracy alone doesn't show that. If the new optimizer just fits better, test accuracy rises without the gap shrinking. Report train accuracy or loss and the gap alongside test accuracy.

**Budget:** this is about 2 x 20 short runs plus a handful of seeds for the two finalists. If that's too much, use fewer configs (8 to 10 each) with a smaller model or fewer epochs. An equal-budget comparison at small scale is worth more than an unequal one at full scale.
