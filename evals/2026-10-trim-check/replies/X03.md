I read this as a Beamer slide figure, so it uses 1.2pt lines, `\small` labels, and higher-contrast colors. It's a standalone `.tex` that you can `\includegraphics` into a frame or paste in as a `tikzpicture`. It needs only base TeX Live packages (TikZ with the `positioning`, `calc` and `arrows.meta` libraries).

The five sources are stacked in one column, and the retriever is centered on that column. That keeps the five arrows symmetric and stops them colliding. All sources share one style and all arrows share one style. Blue marks the input sources, black marks the processing stages, and green marks the final answer.

```latex
\documentclass[tikz,border=6pt]{standalone}
\usepackage[T1]{fontenc}
\usepackage{lmodern}
\renewcommand{\familydefault}{\sfdefault}
\usetikzlibrary{positioning,calc,arrows.meta}

\definecolor{srcblue}{RGB}{0,82,155}
\definecolor{outgreen}{RGB}{0,120,60}

\tikzset{
  % one palette: every box type is defined here and used by name
  base/.style={draw, line width=1.2pt, rounded corners=3pt, align=center,
               font=\small, inner sep=6pt},
  source/.style={base, draw=srcblue, fill=srcblue!10,
                 minimum width=3.2cm, minimum height=0.9cm},
  stage/.style={base, draw=black, fill=black!6,
                minimum width=2.6cm, minimum height=1.4cm},
  output/.style={base, draw=outgreen, fill=outgreen!12,
                 minimum width=2.4cm, minimum height=1.4cm},
  % one arrow style for the whole figure
  flow/.style={-{Stealth[length=7pt]}, line width=1.2pt, black},
  % subordinate labels: small, gray, anchored to their element
  note/.style={font=\small, text=black!60, align=center},
}

\begin{document}
\begin{tikzpicture}[node distance=0.3cm]

  % Forward-pass order:
  % 5 sources -> retriever -> LLM -> answer

  % sources: one column
  \node[source] (s1) {PDFs};
  \node[source, below=of s1] (s2) {Web pages};
  \node[source, below=of s2] (s3) {SQL database};
  \node[source, below=of s3] (s4) {Slack};
  \node[source, below=of s4] (s5) {Email};

  \node[note, above=4pt of s1] {Knowledge sources};

  % retriever centered on the source column
  \coordinate (mid) at ($(s1.east)!0.5!(s5.east)$);
  \node[stage, right=2.2cm of mid] (retriever) {Retriever};

  \node[stage, right=2.4cm of retriever] (llm) {LLM};
  \node[output, right=1.8cm of llm] (answer) {Answer};

  % arrows
  \foreach \i in {1,...,5} {
    \draw[flow] (s\i.east) to[out=0, in=180] (retriever.west);
  }
  \draw[flow] (retriever) -- node[note, above=3pt, midway] {top-$k$\\passages} (llm);
  \draw[flow] (llm) -- (answer);

\end{tikzpicture}
\end{document}
```

Notes:
- The retriever sits at the vertical midpoint of the source column using `($(s1.east)!0.5!(s5.east)$)`, and all five sources have the same width so their east edges line up.
- The "top-$k$ passages" label sits above the retriever-to-LLM arrow, not on it. The "Knowledge sources" caption is anchored above the first source box.
- To animate it in Beamer, add `\usetikzlibrary{overlay-beamer-styles}` and put `visible on=<2->` on the later stages.
