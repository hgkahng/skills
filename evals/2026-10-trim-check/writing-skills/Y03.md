Flask treats the two URLs differently based on how the route is written. `'/api/items'` has no trailing slash, so it matches only `/api/items`, and `/api/items/` returns 404.

To accept both, either:

```python
@app.route('/api/items/')
```

which serves `/api/items/` and redirects `/api/items` to it (308), or

```python
@app.route('/api/items', strict_slashes=False)
```

which serves both URLs directly with no redirect.
