That's normal React behavior, and it's not a bug.

Your input almost certainly stores what the user types in **state**, something like this:

```jsx
const [text, setText] = useState("");
<input value={text} onChange={(e) => setText(e.target.value)} />
```

React's rule is that whenever a component's state changes, React calls your component function again (a "re-render") to work out what the screen should show. Each keystroke calls `setText`, which changes the state, so each keystroke triggers a re-render.

A re-render doesn't rebuild the page. React compares the new result with the previous one and only touches the parts of the page that changed, so it's usually fast enough that you won't notice it.

You only need to act if typing feels slow. In that case, move the input and its state into its own small component, so only that component re-renders on each keystroke.
