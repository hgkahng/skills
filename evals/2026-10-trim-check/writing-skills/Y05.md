Flask treats a route without a trailing slash as an exact match. `@app.route('/api/items')` matches only `/api/items`, so `/api/items/` has no matching rule and returns 404.

To accept both URLs, use either of these:

```python
@app.route('/api/items', strict_slashes=False)
```

This serves both `/api/items` and `/api/items/` directly.

```python
@app.route('/api/items/')
```

Here `/api/items/` is the canonical URL, and a request to `/api/items` gets a 308 redirect to it. Many HTTP clients don't follow redirects by default, and `curl` doesn't unless you pass `-L`.
