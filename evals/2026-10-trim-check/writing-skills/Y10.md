That's React working as designed. Typing in the input updates a piece of state (usually via `useState`), and whenever a component's state changes, React re-runs that component's function to work out what the screen should now show. Every keystroke changes the state, so every keystroke triggers a re-render.

This is normal and cheap. React only touches the parts of the page that actually changed, so the input doesn't flicker or lose focus.

You only need to act if the re-render is slow, for example because the component also does heavy work or contains a big list. If that's your case, share the component code and I'll point to the fix.
