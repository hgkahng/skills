## What the error means

`ModuleNotFoundError: No module named 'torch'` means Python ran an `import torch` (or `from torch import ...`) and couldn't find a package called `torch` in the environment that is running your code. `torch` is PyTorch, the deep learning library. It isn't part of the Python standard library, so it has to be installed separately.

There are two usual causes:

1. PyTorch isn't installed at all.
2. PyTorch is installed, but in a different Python environment from the one running your script. This happens a lot with multiple Python versions, virtualenvs, conda environments, Jupyter kernels, or IDE interpreters.

## The fix

Install PyTorch into the same interpreter that runs your code. Calling pip through that interpreter keeps the two matched:

```bash
python -m pip install torch
```

If you use `python3`, run `python3 -m pip install torch`. On Windows, `py -m pip install torch` works too.

If you use conda, run:

```bash
conda install pytorch -c pytorch
```

For a GPU (CUDA) build, or a specific platform, use the selector at https://pytorch.org/get-started/locally/. It gives you the exact command for your OS, package manager and CUDA version. The plain `pip install torch` gives you a default build, which may not match your GPU setup.

## Check that it worked

```bash
python -c "import torch; print(torch.__version__)"
```

If that prints a version number, you're set.

## If it still fails after installing

Check that your install and your run are using the same Python:

```bash
python -c "import sys; print(sys.executable)"
python -m pip --version
```

The pip path should live under the same environment as the interpreter path. If it doesn't, activate the right virtualenv or conda environment and reinstall.

Other things to check:

- **Jupyter:** the notebook kernel may be a different environment. Run `%pip install torch` in a cell, then restart the kernel.
- **VS Code / PyCharm:** select the interpreter that has torch installed (in VS Code, "Python: Select Interpreter").
- **Python version:** PyTorch only publishes wheels for certain Python versions. If pip says "no matching distribution found," your Python version may be too new or too old for the current release. Use a supported version, which the PyTorch install page lists.
- **A file named `torch.py`** in your project folder can shadow the real library and cause import errors. Rename it if you have one.
