Python can't find PyTorch because it isn't installed in the environment you're running.

Fix: install it with the same Python that runs your script.

```
python -m pip install torch
```

Then run your script again. If you use a virtual environment or conda, activate it first so the install goes into the right place.

If it still fails after installing, check which interpreter is running with `python -c "import sys; print(sys.executable)"`. It should be the one you installed into.

For a GPU build, pick the command for your CUDA version at pytorch.org/get-started/locally.
