Python is telling you it looked for a package called `torch` and couldn't find it. `torch` is PyTorch, a popular library for machine learning. It isn't built into Python, so you have to install it first.

**The fix:** run this in a terminal:

```
pip install torch
```

If you use Python 3 and `pip` points to the wrong version, try this instead:

```
python -m pip install torch
```

Then run your script again.

**If it still fails**, the usual cause is that you installed `torch` in one Python and ran your code with another. This happens a lot with virtual environments, Jupyter, and IDEs like VS Code. To check, run:

```
python -c "import sys; print(sys.executable)"
```

Make sure the path it prints is the same Python you installed `torch` into. In Jupyter, you can install into the right one by running `%pip install torch` in a notebook cell.

**One note:** the plain `pip install torch` gives you a default build. If you have an NVIDIA GPU and want GPU support, get the exact command for your setup from the selector at pytorch.org (under "Get Started").
