A process is a running program. A thread is a unit of work inside a process.

Each process gets its own private memory. Other processes can't see it or change it. A process can have one thread or many.

Threads in the same process share that process's memory. That makes it easy for them to pass data to each other. It also means one thread can corrupt data another thread is using, so you have to coordinate them carefully.

Two other differences follow from this:

- **Cost:** Starting a thread is cheaper than starting a process, and switching between threads is faster.
- **Crashes:** If a thread crashes the whole process, every thread in it dies. If one process crashes, other processes usually keep running.

Use separate processes when you want isolation. Use threads when the work needs to share data quickly.
