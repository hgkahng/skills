**Principle:** Work in this repo should be reproducible and findable by a labmate who wasn't there, so the environment, outputs and branches follow fixed conventions.

**Derived anchors:**
- Hence Python is 3.11, so reruns match the original environment.
- Hence results go in `runs/YYYY-MM-DD/`, so outputs can be found by date.
- Hence experimental branches start with `exp/`, so experiment work is distinguishable.

**Boundary:** the principle covers only the conventions listed here. Don't add new structure, pins or metadata in its name.

**Hard constraints (arbitrary, no deeper reason):**
