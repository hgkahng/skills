```python
def fetch_with_retry(url, max_attempts=3, backoff=2.0):
    """Fetch a URL via HTTP GET, retrying with exponential backoff on failure.

    Each attempt uses a 10-second timeout. If the request raises a
    `requests.RequestException` (e.g. a connection error or timeout), the
    function waits and tries again, unless the failed attempt was the last
    one allowed, in which case the exception is re-raised to the caller.
    The wait before retrying after attempt `i` is `backoff * 2 ** i` seconds,
    so delays grow exponentially — with the default `backoff=2.0`, that's
    2s, then 4s, between successive retries.

    Args:
        url: The URL to request.
        max_attempts: Maximum number of GET attempts before giving up.
            Defaults to 3.
        backoff: Base delay in seconds used to compute the exponential
            backoff between retries. Defaults to 2.0.

    Returns:
        requests.Response: The response from the first successful attempt.

    Raises:
        requests.RequestException: If all `max_attempts` attempts fail, the
            exception from the final attempt is re-raised.
    """
```

I also spelled out the exact backoff formula (`backoff * 2 ** i`) rather than just saying "exponential," since that's the kind of detail people usually have to re-derive by reading the code otherwise.
