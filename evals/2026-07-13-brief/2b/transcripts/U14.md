Not recommended as a default: anything readable by JavaScript is readable by any injected script, so a single XSS bug turns into full token theft, and localStorage persists that exposure across tabs and reloads with no way to mark it httpOnly. Prefer an httpOnly, Secure, SameSite cookie for the token (or keep the access token in memory with a refresh token in such a cookie); only fall back to localStorage if you have strong, audited XSS defenses (strict CSP, output encoding, no unsanitized third-party scripts) and accept the residual risk.
